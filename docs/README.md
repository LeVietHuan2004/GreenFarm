# Tài liệu GreenFarm

- `api/authentication.md`: hợp đồng API tài khoản, JWT và phân quyền.
- `api/catalog.md`: hợp đồng API danh mục, sản phẩm và hình ảnh.
- `api/image-storage.md`: cấu hình Cloudinary, ảnh local cũ và cách kiểm tra upload.
- `api/cart-wishlist.md`: hợp đồng API giỏ hàng và danh sách yêu thích.
- `api/guest-commerce.md`: phiên khách, giỏ khách, checkout, tra cứu đơn và merge.
- `api/orders.md`: hợp đồng API checkout, địa chỉ và đơn hàng khách hàng.
- `api/payments.md`: hợp đồng API thanh toán COD/VNPAY và coupon.
- `api/order-operations.md`: quy trình vận hành đơn cho admin, staff và delivery staff.
- `api/engagement.md`: hợp đồng API review, liên hệ hỗ trợ và thông báo.
- `api/loyalty.md`: quy tắc tích điểm, đổi điểm và API GreenFarm Rewards.
- `api/coupons.md`: quy tắc coupon/voucher, checkout, vòng đời lượt dùng và API quản trị.
- `api/reports.md`: API và quy tắc tính báo cáo kinh doanh trên dashboard admin.
- `api/inventory.md`: quản lý kho theo lô, FEFO, lịch sử và nhà cung cấp.
- `design/`: tài liệu thiết kế module và luồng nghiệp vụ ở các giai đoạn sau.
